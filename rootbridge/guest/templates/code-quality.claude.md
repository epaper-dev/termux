## Code quality requirements

- Follow the project's coding conventions.
- Prefer simple and readable code.
- Keep changes minimal and focused.
- Avoid unnecessary abstractions and wrappers.
- Avoid deep nesting and duplicated logic.
- Use descriptive names and clear expressions.
- Reuse existing APIs and helper functions.
- Preserve behavior unless changes are requested.
- Never refactor unrelated code.
- Run formatting, tests and static checks.
- Review the diff for unnecessary complexity.
- Avoid repeated automatic fix-and-review loops.
- Prefer the smallest correct solution,
  not necessarily the fewest lines.
