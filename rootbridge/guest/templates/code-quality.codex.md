## Code Quality

- Generate clean, simple, idiomatic code.
- Follow the existing project's coding style.
- Prefer readability over cleverness.
- Minimize nesting and complex expressions.
- Avoid unnecessary type casts and wrappers.
- Use meaningful variable names.
- Avoid duplicated logic.
- Prefer existing functions and abstractions.
- Keep changes as small as reasonably possible.
- Do not introduce speculative defensive code.
- Never sacrifice maintainability for brevity.
- Before finishing, critically review your own code
  for unnecessary complexity and simplify it.
- Run the project's formatter and relevant tests.
- Do not modify unrelated code.
